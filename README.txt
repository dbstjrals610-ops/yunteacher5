우리 반 3D 우주 전시관 (천체관측관 포함) — 올리는 방법
=================================================

[파일 구성] — 저장소(예: yunteacher5)에 이 구조 그대로 올립니다
  index.html              : 학생 입장 → 천체관측관 → 3D 전시관, 선생님 페이지(?t=1)
  setup.html              : 처음 1번만 하는 Firebase 연결 설정
  config.js               : setup.html 7단계에서 받은 파일 (이미 올렸다면 그대로 두기)
  observatory/index.html  : 천체관측관 (망원경 조립 · 밤하늘 관측). index.html 안에 자동으로 열립니다

[주소]
  학생 입장   : https://아이디.github.io/저장소/?c=전시코드   (선생님 페이지의 QR)
  선생님 페이지: https://아이디.github.io/저장소/?t=1

[학생 흐름]
  QR → 코드·번호·이름·캐릭터 → 🔭 천체관측관(망원경 조립 → 밤하늘 관측)
  → 사진을 1장 이상 찍으면 위쪽 '🏛️ 3D 전시관 들어가기'가 열림
  → 관측 사진 상세 화면의 '이 사진을 우리 반 전시관에 걸기' 또는 전시관의 '사진 올리기'에서
     내 관측 도감 사진을 골라 올리기 (설명 자동 입력, 내 생각 덧붙이기)
  → 전시관 앞 🎫 매표소에서 입장권 받기 → 정문 개찰구 통과
  → 1층·2층 전시실 A~D, 복도, 2층 → 1층 미끄럼틀, 지하 1층 태양계 모형관
  → 액자 누르면 크게 보기 · 박수 · 한 줄 감상, 방명록, 작품 목록에서 바로 이동
  → 위쪽 '🔭 관측관' 버튼으로 다시 관측하러 갈 수 있음

[선생님 페이지]
  전시회 만들기(6자리 코드·링크·QR), 칠판에 크게 띄우기, 전시관 열기/닫기,
  학생 사진 올리기 켜기/끄기, 작품 숨기기/삭제, 방명록 비우기, 전시회 삭제

[작품 배치]
  작품 수에 맞춰 자동으로 나눠 겁니다 (9점마다 전시실 1개):
  1층 A → 1층 B → 2층 A → 2층 B → 1층 C·D → 2층 C·D → 지하 1층.
  같은 분류(항성·행성·위성…)끼리 모이고, 전시실 문패에 분류가 표시됩니다.

[무료 한도 참고]
  Firebase 무료(Spark): 저장 1GB, 내려받기 월 10GB, 동시 접속 100명.
  사진은 자동으로 줄여 저장하므로 한 반 30명 수업은 여유 있습니다.
