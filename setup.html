🛠️ 처음 설치 (선생님 1회)

이 페이지는 전시관을 처음 설치하는 선생님만 쓰는 곳이에요. 이미 설치를 마쳤다면 처음 화면의 선생님 로그인으로 가세요. 학생은 이 페이지가 필요 없어요.

한 번만 하면 돼요 (약 10분). 학생들이 올린 사진은 선생님 Google 계정의 무료 Firebase 저장소에 저장돼요. 무료(Spark) 요금제라 결제 정보가 필요 없어요.

1Firebase 프로젝트 만들기

  1. console.firebase.google.com 에 학교(또는 개인) Google 계정으로 로그인
  2. 프로젝트 만들기 (또는 Firebase 프로젝트 시작하기) → 이름 예: space-gallery → Google 애널리틱스는 사용 안 함 → 만들기

2로그인 방법 켜기 (Authentication)

  1. 왼쪽 메뉴 보안 → Authentication → 시작하기 (예전 화면은 ‘빌드(Build)’ 아래)
  2. 로그인 방법(Sign-in method) 탭에서 익명(Anonymous) → 사용 설정 → 저장 (학생용: 학생은 계정이 필요 없어요)
  3. 새 제공업체 추가 → 이메일/비밀번호 → 사용 설정 → 저장 (선생님용)

3데이터베이스 만들기 (Realtime Database)

  1. 왼쪽 메뉴 데이터베이스 및 스토리지 → Realtime Database → 데이터베이스 만들기 (예전 화면은 ‘빌드’ 아래)
  2. 위치: 싱가포르 (asia-southeast1) 선택 → 잠금 모드로 시작 → 사용 설정
  3. 화면 위쪽에 보이는 주소(https://….firebasedatabase.app)를 기억해 두세요.

⚠️ Firestore Database가 아니라 Realtime Database예요.

4웹 앱 등록하고 설정값 복사

  1. 왼쪽 메뉴 ⚙️ 설정 → 일반 (예전 화면은 ‘프로젝트 설정’) → 맨 아래 내 앱에서 </>(웹) 아이콘
  2. 앱 닉네임 아무거나 (예: gallery) → Firebase 호스팅은 체크하지 않음 → 앱 등록
  3. 나오는 코드 중 const firebaseConfig = { … }; 부분을 통째로 복사해서 아래에 붙여 넣기

5선생님 계정 만들기 + 연결 확인

전시회를 만들고 관리할 때 쓰는 선생님 전용 계정이에요. 실제로 쓰는 이메일 주소면 돼요. (Google 비밀번호와 다르게 정하세요)

6보안 규칙 붙여넣기

아래 규칙을 복사해서 Firebase의 Realtime Database → 규칙(Rules) 탭에 원래 내용을 모두 지우고 붙여 넣은 뒤 게시를 누르세요.
학생은 자기 사진만 올리고 지울 수 있고, 전시회 관리(숨기기·삭제·설정)는 선생님 계정만 할 수 있게 해 줘요.

(5단계를 먼저 해 주세요)

7config.js 파일을 GitHub에 올리기

아래 버튼으로 config.js를 내려받아, index.html · setup.html과 같은 GitHub 저장소(같은 폴더)에 올려 주세요. (Add file → Upload files)
1~2분 뒤 GitHub Pages에 반영되면 끝!

(6단계를 먼저 해 주세요)
